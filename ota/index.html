INXICO OTA resources

This repository hosts INXICO's public data-only over-the-air resource channel.

No native application code is distributed here. Swift/Kotlin/Java binaries, dynamic libraries, scripts, bytecode and executable plugins are outside the OTA contract and must ship through normal app distribution.

Allowed resource classes

  • prompts;
  • JSON configuration;
  • non-executable assets;
  • signed model-catalog metadata that feeds INXICO's separate model-trust pipeline.

Integrity model

Production manifests are designed to be signed with Ed25519. Resource bytes are pinned by SHA-256 and activated only after verification. The private signing key must never be published in this repository.

Production feed path: https://christophermarcellino.github.io/INXICO-Public/ota/v1/manifest.json

The production manifest is intentionally absent until a production signing key and first signed release are prepared.
