# INXICO OTA v1

This directory is the production location for the signed INXICO OTA resource manifest.

Expected public URL:

`https://christophermarcellino.github.io/INXICO-Public/ota/v1/manifest.json`

Do not create an unsigned production manifest. The Ed25519 private signing key must remain outside this repository. Resource classes and verification rules are defined in the private INXICO application repository.
